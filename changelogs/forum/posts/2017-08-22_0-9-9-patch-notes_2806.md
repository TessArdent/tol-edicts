# 0.9.9 Patch Notes

- Date: 2017-08-22 19:17:35 UTC
- Author: Ellie
- Archived copy: https://fol-archive.netlify.app/t/0-9-9-patch-notes/2806.html

## General:

- Dead players now have ghost textures. Spooky!
- Added a room for the Princess and Fool.
- If a player is inactive for 2 days, they will be killed.
- 6 new executions have been added.
- 4 new armors have been added.
- If the game freezes, it should return everyone to the main menu.
- Updated some in-game UI elements.

## Weapons:

- Heaven’s Sword (Holy Strike)
- Abaddon Axe (Hell’s Fury)
- Warden’s Bludgeon (Clobber)
- Vortex Amulet (Energy Flux)
- Frozen Rune (Conjure Ice)
- Rune of Focus (Ahemak Blast)

## Armor/Skins:

- Drake-Hide Leather Tunic (Working Now)
- Basalt Armament
- Noble’s Gown
- Crimson Regalia

## Alchemist:

- Can no longer target king with Emerald Potion.

## Court Wizard:

- Magical Barrier still had the old description for the ability. Now correctly states, “Protects a player from negative effects tonight. Does not block kills or converts.”

## Drunk:

- Happy Hour now makes both the Drunk and his target immune to conversion for the night.
- Debauchery will not force the Cult Leader or Mastermind to convert you.

## Hunter:

- Spike Traps makes the Hunter immune to conversion for the night.

## Possessor:

- Now appears as Possessor if they die.
- Can no longer possess player if they were killed by someone else that night.
- Poison and bleed from the Possessor’s victim will affect the Possessor while they are in that body.

## Scorned:

- Can now only start with Blue Dragon targets.
- Will commit suicide if all targets die, without winning.
- Targets has been reduced to 2.

## Sheriff:

- Scout is now a day ability.

## Improvements:

- New users no longer need to activate emails. Yes!! This may change, but hopefully not :slight\_smile:
- Text in the login screen and lobby has been upscaled.
- Some gfx polish in the lobby.
- Friends list now reflects your selected title, although there’s only 1 right now except for staff.
- Friends list now reflects your selected avatar, although… ^

## Changes:

- We ditched a crappy data system and swapped to a new one with TONS of potential new features. This means a few things have reset. Please keep an eye out for new bugs.
- You will be asked again for your email. You DONT need to activate it!
- Your gp and inventory has reset – but here’s 300gp on us!
- Friends list has had a complete revamp. You can’t interact with people, yet, but soon you’ll be able to to interact without Steam, approve/deny/request friends, and more!
- We now track name change history: Watch out! Better not to troll at all.
- Soon, you won’t be able to play if you use a proxy to hide your IP to avoid IP bans. If this is an issue in your country, private message Xblade.

## Bug Fixes:

- Possessor bug fixes.
- Scorned bug fixes.
- Tons of bug fixes that froze you at “verifying version” due to our old friends list
- Private matches should now HIDE the vote change host button
- Public matches should now SHOW the vote change host button
- Friends list is no longer buggy (although temporarily downgraded)
- Drake-Hide Leather Tunic should now work in-game.
- Others.
