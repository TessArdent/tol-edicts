# (***UPDATE) v6.0.0 : Brand new game mode - “Quick Mode” is now available!

- Author: Chocobo Knight
- Feed: Community Announcements

![](https://clan.cloudflare.steamstatic.com/images/27884844/7b743926ed4ead68157a34cf42246d10b77e5509.jpg)
Brand new game mode - “Quick Mode” is now available! Two main updates-

1. It only starts with 6 players using the selected characters in Tol.
2. The occupation of the defeated player will no longer be revealed.

Detail :

- Quick mode :

- 6 players to start. (4 Blue Dragon, 1 Fool , 1 Enemy)

- Only 11 selected classes in this mode.

- No Unseen, Cult, Conversion in this mode.

- BD opposite faction "Enemy" : Assassin, Sorcerer, Psycho King.

- Modified abilities only in "Quick mode". (charge numbers, disabled)

- No death reveal : players will not be revealed the class.

- *For more information about classes, please check Role Info in game.

- Public game (from "Play Now") : Only "Quick mode" with 6 players.

- Private game (from Create Group): You can play "Quick mode" with 6 players, "Classic mode" with 6+ players.

- New UI for lobby banner and player list.

- New UI for vote and whisper buttons.

- Fixed the freezing screen issue in Classic mode.

- Dynamic class list on top right screen in game.

- New graphic fx for in-hand magical weapons.

- Custom room settings for day and night round time for private game.

- Revamp Noble ability "Gossip" : You will receive the class types who visit your target.

- Revamp Aristocrat ability "Intrigue" : You will receive the class types who visit your target, and frame your target.

- Rename "Class Card" to "Role Info".

- Fixed hover feature in Chinese version.

For more support please email : support@throneoflies.com

Can’t wait to see you in the most exciting Tol "quick mode".
