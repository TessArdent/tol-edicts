# 1.0.10 Patch notes

- Date: 2017-11-21 13:56 UTC
- Author: Boslof
- Feed: Community Announcements
- Original: https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/2486412956119640351

---

## General:

- Noble has been removed for the time being.

## Court Wizard:

- Is now unique, so only 1 can spawn per game.

## Inquisitor:

- Holy Blessing now only provides one night of immunity.

## Hunter:

- Bear Companion now prevents all attacks as well as killing the attackers. This means even attacks that bypass night immunity will not kill them.

## King:

- Allies has been reverted, but now all Kings will see the player’s faction.

## Prince:

- Can only imprison the same player 3 times, and it now counts towards the occupation count.

## Psychic:

- No longer unique.
